# 🔧 Creating an Exploded View: Mechanical Keyboard Switch

An exploded view is a way of showing the different parts of an object by separating them from their original positions while keeping their arrangement and orientation intact. It makes it easier to understand how an object is built and how its components fit together.

In this documentation, I will explore how to create an exploded-view illustration of a mechanical keyboard switch manually, using drawing tools instead of AI-generated images.

## 1. Understanding an Exploded View

An exploded view is commonly used in engineering drawings, repair manuals, and product documentation. It helps us see the internal structure of an object without having to physically dismantle it.

It can be useful for:
- Identifying individual components.
- Understanding how different parts are connected.
- Visualizing the assembly and disassembly process.
- Explaining the internal design of a product.

## 2. Choosing the Component

For this exercise, I chose a mechanical keyboard switch because it has several small components arranged in a specific way.

A typical mechanical switch consists of:

1. Upper housing
2. Stem
3. Spring
4. Lower housing
5. Electrical contact mechanism

The exact design may vary depending on the switch model, so it is important to refer to an actual switch or a reliable technical reference.

## 3. Researching the Components

Before starting the drawing, I need to understand what the switch looks like internally and how its components are arranged.

Some useful references include:

- Manufacturer diagrams.
- Teardown photographs.
- Technical drawings.
- Repair guides.
- Physical inspection of an actual switch.

This step helps avoid drawing parts incorrectly or placing them in positions that do not match the actual assembly.

## 4. Tools Required

The illustration can be created using any drawing software that supports shapes, lines, and layers.

Some tools that can be used are:

- Inkscape
- LibreOffice Draw
- diagrams.net
- PowerPoint
- Other vector or drawing applications

The entire illustration can be created manually by drawing shapes, adjusting their positions, and adding labels. No AI image generation or prompting is involved.

## 5. Planning the Exploded View

Since the components of a mechanical switch are arranged vertically, separating them along the same axis makes the illustration easier to understand.

The parts can be arranged from top to bottom in their assembly order.

```text
          ┌─────────────────┐
          │  Upper Housing  │
          └─────────────────┘
                  |
                  |
             ┌─────────┐
             │  Stem   │
             └─────────┘
                  |
                  |
               /\/\/\
                Spring
                  |
                  |
          ┌─────────────────┐
          │  Lower Housing  │
          └─────────────────┘
```

This is only a basic layout to understand how the parts will be separated. The actual drawing should represent their shapes and proportions more accurately.

## 6. Creating the Illustration

### Step 1: Set Up the Canvas

First, create a new document with enough space for the drawing and its labels. A landscape layout works well because it provides room for annotations on both sides.

### Step 2: Draw the Components

Using the selected drawing software, create the basic shapes of the switch components. I can use rectangles, curves, polygons, and other drawing tools to represent their geometry.

The goal is to keep the shapes and proportions as close to the reference as possible.

### Step 3: Separate the Parts

Once the components are drawn, move them apart along the assembly axis.

The spacing should be enough to clearly distinguish each part without making the entire illustration look disconnected.

### Step 4: Maintain Their Orientation

While separating the parts, their original orientation should remain consistent. This helps the viewer understand how they fit together when the switch is assembled.

### Step 5: Add Guide Lines

Thin dashed lines can be used to indicate the original alignment of the components.

These lines help explain how the parts relate to one another, especially when there are several components.

### Step 6: Add Labels

Each component should have a clear label.

Leader lines can connect the labels to the corresponding parts. They should be positioned carefully so they do not overlap the drawing or make it difficult to read.

### Step 7: Add Additional Information

If necessary, I can include short annotations explaining the function of a component, the direction of assembly, or any important feature.

Any technical details, such as material or dimensions, should only be included if they have been verified.

### Step 8: Improve the Appearance

After completing the basic drawing, I can improve its visual appearance by adjusting:

- Line thickness.
- Spacing between components.
- Font size and style.
- Colours used to distinguish parts.
- Background and contrast.

The illustration should remain simple enough that someone can understand it without needing additional explanations.

### Step 9: Export the Final Drawing

After reviewing the illustration, I can export it as a PNG or PDF file.

If the software supports it, saving an editable SVG or project file is also useful so that I can make changes later.

## 7. Final Layout
